# 家有余量 · 家庭现金流与目标规划

把家庭资产负债、月度收支和目标付款日放在同一份24个月现金账。第一版提供独立 React 演示和 Wealthfolio Addon，共用计算核心与界面。所有内置家庭均为合成案例。

## 运行与构建

需要 Node >=22.18、npm；ZIP 打包需 Python 3（仅标准库）。已用 Node 26.3.1 验证。没有外部 API、模型密钥、数据库或绝对路径依赖。

```sh
npm ci
npm test
npm run typecheck
npm run dev
# http://127.0.0.1:5173
npm run build
npm run verify:addon
npm run preview
# http://127.0.0.1:4173
```

构建分别产出 `dist/` 独立演示（可放任意静态服务器，相对 base）；`addon/dist/addon.js` 与 CSS 插件文件；`cn-family-cashflow-addon.zip` 包含根目录 manifest、dist、说明及许可，无 node_modules。

本版不调用模型。解释材料导出当前输入、来源、基准/情景确定性结果及提示词，由用户检查后自行交给模型。

## 插件安装与验证边界

目标 Wealthfolio SDK 3.9.0，固定提交见 [UPSTREAM.md](UPSTREAM.md)。在对应宿主 Add-ons 的安装 ZIP 入口选择构建文件，查看只读账户/估值/独立资产与文件保存权限。侧栏“家有余量”进入，实际菜单依宿主版本而定。

真实 `enable(ctx)` / `ctx.router.add` 入口；读取候选调用 SDK 账户、估值、独立资产 API。必须逐项勾选家庭资料，应用后替换资产/负债，并清空案例收支、目标和还款。只支持 CNY，不自动换汇；缺失/不完整估值显示原因。宿主估值不能证明公司归属或账户是否冻结，现金候选仍须人工确认。

保存：独立演示为浏览器 localStorage，插件为 scoped 宿主 storage（同步由宿主设置决定）。插件导出真实调用 `files.openSaveDialog`，区分成功、取消与失败。导入使用 DOM File API 本地解析，不直接访问宿主数据库。

已实际运行：领域/导入/适配器单元测试，typecheck，独立与 addon 构建。适配器测试用真实函数加 API 返回桩。**尚未验证真实 Wealthfolio 安装、权限提示、存储、保存对话框与热加载**；未运行 Rust 宿主。独立演示标明本地保存，读取宿主返回未连接说明。

## 使用步骤

1. 选合成家庭，或导入自己的 JSON。切换替换未保存编辑，可先导出备份。
2. 在“三张表与明细”修改资产归属、收支、付款日、来源。离开输入框或 Enter 后校验应用；错误回退该次输入。批量改月份与日期可用整体 JSON 编辑。
3. 切基准/工资中断情景；点月份查看逐笔来源。月内最低余额保留目标先付、工资后到造成的缺口。
4. 保存后可恢复；JSON可往返。坏文件不覆盖有效计划；坏存储显示错误并回到明确合成案例，保存前不覆盖原存储。

读取与保存/导出期间禁用编辑，避免慢宿主覆盖新输入。文件上限200KB、每类200条；金额最多两位小数，内部0至100亿元整数分，合计另查安全整数。缺失金额不转零。

## 业务口径

- 期初现金只计家庭 cash；房产、证券等仅算期初净资产，不自动变现。企业资产和收支排除。家庭内部转账不应作为新收入录入。
- 工资、家庭经营净收入、其他收入和确认分红算收入。借款增加现金和负债；本金同时减少两者，利息只减现金。未确认事件不计入。
- 第一个月完整计入收支，持续24个月。按日期排序，同日先收入/借款，再按ID出账，尚无日内时刻；需预留缓冲。负数为未筹措缺口，不自动借款。
- 工资中断前N月只停工资，其他项目沿用。24个月最低现金与第6个月月末余额分别显示。
- 净资产为期初快照，不预测税费、投资收益、通胀、汇率或自动变现。目标按现金支出；购房后新增资产等联动未实现。
- 还本不能超对应余额；还款表与月度或同月一次性还款不能重复。采用银行给定本金/利息表，不作贷款报价。

## 还款 CSV

先建家庭负债，复制列表名称下的 ID。UTF-8（可BOM），单位元，最多2位小数/200行。表头必须如下；来源不能含逗号，本窄格式不支持引号字段、编码或列含义猜测。

```csv
date,loan_id,principal_yuan,interest_yuan,source
2026-10-28,loan,5000.00,300.00,银行还款表第1期
```

导入替换整张表，日期须在24个月内。第三个样例可导出模板；`examples/` 提供三个可导入 JSON 和还款 CSV。JSON保留完整来源文本。

## 验收样例

- 林家：现金12万，月工资2.5万，消费1.2万+本金0.4万+利息0.2万。第6月末付教育费15万，基准余1.2万，前6月停薪缺13.8万。
- 周家：企业80万排除；家庭现金12万，确认分红3万、借款20万后现金35万；收入3万、负债20万。
- 陈家：合成贷款12万元，24期等额本金每期5000元，利息单列，末期负债归零；非银行报价。

入口：`src/domain.ts` 计算/校验；`src/import.ts` JSON/CSV；`src/adapters.ts` 两种适配器；`src/addon.tsx` 插件；`tests/` 不变量及 API 桩测试。
